# TM bygg – hugmynd að forsíðu

Hönnunartillaga frá Garðari (Gardarvefur), án skuldbindingar. Þetta er **ekki** opinber vefur TM bygg ehf.

## Staðfestar upplýsingar

- TM bygg ehf., kt. 450804-2820, skráð 6. ágúst 2004, Steinási 31, 260 Reykjanesbæ ([karp.is](https://karp.is/fyrirtaeki/tm-bygg-ehf-4508042820/), byggt á fyrirtækjaskrá).
- ÍSAT 43.31.0 Múrhúðun.
- Á félagaskrá Múrarameistarafélags Reykjavíkur; tengiliður Trausti Már Traustason ([si.is](https://www.si.is/murarameistarafelag-reykjavikur-mm)).
- Sími 897 6678, netfang tmt@simnet.is.

## Til staðfestingar hjá TM bygg

- Flísalagnir og Viðgerðir og endurbætur eru merktar „Til staðfestingar“ á síðunni. Allar þjónustulýsingar eru drög.
- Hvort Trausti er eigandi (síðan segir aðeins „tengiliður“).
- Orðalagið „byggingarframkvæmdir“ í inngangi.
- Myndir af raunverulegum verkum og merki fyrirtækisins, ef það er til.
